No `emb run --send` corrects the worker for a gap that exists only against a detail the owner's request does not state, such as handling of an unknown option or a test that standard error is exactly one line, unless Claude names a concrete case in which the commit gives a wrong result, loses work or breaks a caller or test. A run that sends no correction passes. A correction that names such a case passes.
